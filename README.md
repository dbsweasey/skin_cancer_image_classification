# Skin Cancer Image Classification
This project displays work with PyTorch and training a custom convolutional neural network. It outlines each step of model construction, training, testing, and evaluation. 

## My Contributions
As shown, this was a group project. I upload it to my personal GitHub to highlight my technical contributions and achievements.
I was responsible for the entirety of the Jupyter Notebook. I located the Kaggle dataset and ensured it was cleaned and wrangled.
With the help of PyTorch, I created a fair train/test split.
I trained the model, tested and evaluated the model, made hyper-parameter tweaks, and created the confusion matrix, testing metrics, and feature map. 
I wrote much of the technical detail regarding the CNN in the report. 

## Components
- Uses a 10,000 image dataset from Kaggle
- Shows step by step code to train a CNN
- Uses either a custom model or ResNet18
- Provides testing metrics and a confusion matrix for model evaluation
- Shows feature map of first N layers to visualize what the model sees
